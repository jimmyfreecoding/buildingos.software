## 软件详细信息

### 硬件环境
- **软件开发硬件环境**：
  PC机：Intel Core i7或同等规格处理器，RAM≥16GB，硬盘≥512GB。
- **软件运行硬件环境**：
  智能屏终端：墙装平板（8-12寸，Android/Windows，分辨率1920×1200或1280×800，支持触控）、电视大屏（1080P/4K，HDMI输入）、数字孪生大屏（3840×2160，GPU支持4K渲染）。
  门牌屏/卫生间屏：7-10寸触控平板，支持MQTT/HTTP联网。
  边缘网关：x86 四核、8GB RAM、SSD 128GB，千兆以太网，MQTT/HTTP。
  服务器：x86 8核、16GB RAM、SSD 512GB；或云主机同等规格。
  网络与供电：千兆交换机、UPS≥1KVA、PoE（如需）。

### 软件环境
- **开发该软件的操作系统**：Windows 11 / macOS 14
- **软件开发环境/开发工具**：Node.js 20.x、Vite、Vue 3、TypeScript 5.x、Tailwind CSS、pnpm/npm
- **该软件的运行平台/操作系统**：Linux（Ubuntu 22.04）/ Android / Windows（终端侧）
- **软件运行支撑环境/支持软件**：Nginx、MQTT Broker（EMQX/Mosquitto）、Docker

### 编程语言
- **编程语言**：TypeScript 5.x、CSS
- **源程序量**：约15000行

### 开发目的
- **内容**：为楼宇智能终端提供统一的可视化控制与信息展示界面。

### 面向领域/行业
- **内容**：智慧楼宇、园区智能终端与可视化控制行业。

### 软件主要功能
- **内容**：
  本软件实现楼宇内各类智能屏终端（墙装平板、电视大屏、门牌屏、卫生间屏等）的统一控制与信息展示，包括首页多模块总览（照明、气候、环境）、照明分区控制、空调温控、空间占用查看、能耗统计图表、室内外空气质量监测、综合服务扫码、会议室设备控制、数字孪生大屏展示、视频会议联动、卫生间状态监测及门牌信息展示；支持16:9/16:10/1:1多分辨率等比缩放适配，通过MQTT实现设备状态订阅与控制指令下发。

### 软件主要技术特点
- **分类**：物联网软件 智慧城市软件 企业管理软件
- **详细说明**：
  采用Vue3+TypeScript+Vite+Tailwind CSS架构；基于v-scale-screen实现1920×1200设计稿的多分辨率等比缩放适配；采用MQTT协议实现设备状态实时订阅与指令下发，支持指令-响应关联与断点续传；Pinia统一状态管理，ECharts实现能耗与环境数据可视化。
