# 集成开放平台接口文档

## 一、平台简介

BuildingOS AI 集成开放平台采用 RESTful API 架构，面向第三方系统与开发者提供标准化数据接口。

- **接口协议**：HTTP/HTTPS RESTful
- **数据格式**：JSON
- **认证方式**：JWT Bearer Token（用户登录获取）/ API Token（应用注册获取）
- **Base URL**：`https://<domain>/api`
- **Swagger 文档**：`https://<domain>/api#`

## 四、认证与使用说明

### 4.1 认证方式

平台支持两种认证方式：

**JWT Bearer Token（用户认证）**
- 通过 `/login` 接口获取 Token，有效期 24 小时
- 请求头携带：`Authorization: Bearer <token>`
- 适用于 Web 管理后台、H5 移动端等用户交互场景

**API Token（应用认证）**
- 在 "API客户端管理" 模块注册应用获取 AppID/AppSecret
- 通过 `/api/token` 接口换取访问令牌
- 适用于第三方系统对接、自动化脚本等非交互场景

### 4.2 通用响应格式

```json
{
  "code": 200,
  "msg": "success",
  "data": { }
}
```

### 4.3 分页参数

支持分页的列表接口统一使用：
- `pageNo`：页码（默认 1）
- `pageSize`：每页条数（默认 20）
- 响应中返回 `total` 总数

### 4.4 接口地址

- **本地开发**：`http://localhost:3001/api`
- **生产环境**：`https://<部署域名>/api`
- **Swagger 文档**：`https://<部署域名>/api#`
