# 3.4 访客管理

## 需求概述

本系统提供覆盖访客邀约、审批、签到、通行、离场全流程的一体化访客管理解决方案。支持员工发起邀约、访客自助签到、飞书审批联动、历史访客复用、通行二维码生成、访客机管理、运营管理和精细化邀约权限管控。同时与门禁、停车、梯控等模块原生联通，访客到访自动获得限定区域的通行权限，离场后权限自动回收。

---

## 3.4.1 整体架构

### 访客全生命周期

```
员工发起邀约
    │
    ├── 填写访客信息（支持历史访客复用）
    ├── 设置到访时间、访问区域、对接人
    ├── 添加同行人（可预设最大人数）
    └── 提交申请
          │
          ▼
    审批流（可选，配置飞书审批）
          │
          ▼
    审批通过 → 自动生成访客通行权限
          │
          ├── 短信/微信通知访客（含通行链接）
          ├── 门禁权限自动下发
          ├── 停车权限自动下发（如有车辆）
          └── 梯控权限自动下发
          │
          ▼
    访客到访
          │
          ├── 扫码签到（扫描预约码）
          ├── 出示通行二维码过门禁
          ├── 访客机自助登记
          └── 访客自助添加同行人（通过短信链接）
          │
          ▼
    访客在园
          │
          ├── 实时通行轨迹追踪
          ├── 运营管理（在途行程监控）
          └── 支持提前结束行程
          │
          ▼
    访客离场
          │
          ├── 离场通知（短信/微信通知被访人）
          ├── 门禁权限自动回收
          ├── 停车权限自动回收
          └── 梯控权限自动回收
```

### 路由与功能模块

系统在 `/os/#/sence/visitor/` 下包含以下功能页面：

| 路由 | 模块 | 说明 |
|------|------|------|
| `/sence/visitor/list` | 访客列表 | 主视图，6 个状态标签页管理所有访客申请 |
| `/sence/visitor/statistics` | 访客统计 | 数据仪表盘：邀请总量、到访量、分类、24h 流量趋势 |
| `/sence/visitor/setting` | 系统设置 | 通知设置、邀请参数、审批流配置 |
| `/sence/visitor/kiosk` | 访客机管理 | 自助访客机设备全生命周期管理 |
| `/sence/visitor/permission` | 邀约权限 | 精细化邀约权限管控 |
| `/sence/visitor/operation` | 运营管理 | 在途行程监控与操作 |
| `/sence/visitor/qrcode` | 通行二维码 | 二维码生成与签到记录查询 |

## 3.4.2 访客列表与状态管理

### 六状态标签页

访客列表是访客管理的核心操作界面，采用卡片式布局 + 六状态标签页的设计，帮助运营人员快速定位和处理不同阶段的访客申请：

| 标签页 | 状态标识 | 类型码 | 说明 |
|--------|---------|--------|------|
| 全部 | `all` | 0 | 展示所有访客申请记录 |
| 待到访 | `pending` | 1 | 已审批通过、访客尚未到达 |
| 已到访 | `arrived` | 2 | 访客已签到，正在园区内 |
| 部分待访 | `partial` | 3 | 多人同行中有部分人员已到、部分未到 |
| 已失效 | `expired` | 4 | 超过到访时间窗口未签到，自动失效 |
| 申请异常 | `abnormal` | 5 | 审批异常、权限下发失败等需人工介入 |

**查询条件**：支持按日期筛选，一键查询。每个标签页独立维护查询状态和分页。

### 访客卡片信息

每条访客申请以卡片形式展示，包含以下关键信息：

| 字段 | 说明 |
|------|------|
| 申请编号 | 系统自动生成的唯一编号 |
| 状态标签 | 彩色状态标签（待到访-蓝色/已到访-绿色/已失效-灰色/异常-红色） |
| 访客姓名 / 单位 | 访客及所属单位名称 |
| 访问大楼 | 目标访问园区/楼栋 |
| 访问时间 | 到访时间范围（起止日期时间） |
| 访问类别 | 业务合作 / 面试 / 其他 |
| 对接员工 | 内部被访人姓名 |
| 异常原因 | 当状态为"申请异常"时，显示具体异常描述 |

### 卡片快捷操作

| 操作 | 说明 |
|------|------|
| 邀请链接 | 一键复制访客邀约链接，可通过短信/微信发送给访客 |
| 查看详情 | 打开详情抽屉（VisitorDetail），展示完整申请信息和访客名单 |
| 结束行程 | 仅"已到访"状态可见，提前结束访客在园行程，回收通行权限 |

## 3.4.3 访客邀约

### 邀约表单

发起访客邀约时，员工通过右侧抽屉式表单（VisitorApply，宽度 80%）填写以下信息：

**基本信息区：**

| 字段 | 组件 | 验证 | 说明 |
|------|------|------|------|
| 访客单位 | 文本输入（最多 100 字） | 必填 | 访客所属公司或组织名称 |
| 来访时间 | 日期时间范围选择器 | 必填 | 精确到秒，格式 `YYYY-MM-DD HH:mm:ss` |
| 访客区域 | 下拉选择 | 必填 | 目标园区/楼栋 |
| 访客楼层 | 下拉选择 | 必填 | 目标楼层（如 26F、27F） |
| 访问类别 | 下拉选择 | 必填 | 业务合作 / 面试 |
| 对接人 | 下拉选择 | 必填 | 内部被访员工 |
| 是否需要网络 | 单选 | 必填 | 需要 / 不需要，选需要时展示网络配置说明 |
| 访问事由 | 多行文本（最多 300 字） | 选填 | 来访目的详细说明 |
| 含海外访客 | 单选 | 必填 | 是 / 否 |

**网络配置提示**：当选择"需要网络"时，自动展示网络配置说明和 Mac 地址获取方法指引。

### 访客名单（可编辑表格）

访客名单采用行内可编辑表格，支持灵活增减访客：

| 字段 | 说明 | 验证 |
|------|------|------|
| 来宾姓名 | 访客姓名 | 必填 |
| 来宾职位 | 访客职务 | 选填 |
| 联系电话 | 手机号码 | 必填 |
| 身份证信息 | 身份证号 | 选填 |
| 来访车辆车牌号 | 车牌号码 | 选填 |
| 电脑 Mac 地址 | 网络访问凭证 | 需网络时必填 |

**名单操作：**

| 操作 | 说明 |
|------|------|
| 添加访客 | 点击虚线"添加访客"按钮新增空白行 |
| 移除访客 | 每行右侧"移除"按钮 |
| 批量删除 | 勾选复选框后批量移除 |
| 导入明细 | 从 Excel 批量导入访客名单 |
| 下载明细模板 | 下载标准导入模板文件 |

### 邀约参数控制

邀约行为受系统配置参数约束：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 最大邀约人数 | 20 | 1-20 | 单次邀约可添加的访客数量上限 |
| 最大预约天数 | 7 | 1-30 | 最早可预约未来多少天内的访问 |
| 最早可预约天数 | 1 | 1-30 | 不可预约当日，最短提前天数 |

表单加载时自动获取参数配置，超出限制时阻止提交并给出提示。

## 3.4.4 历史访客复用

### 选择历史访客

员工发起邀约时可一键复用历史访客信息，避免重复录入：

1. 点击"选择历史访客"按钮，弹出 70% 宽度的历史访客选择窗口
2. 系统展示所有历史访客的概要信息表格，支持按姓名/电话/公司关键字搜索
3. 勾选目标访客后点击确认

**历史访客数据字段：**

| 字段 | 说明 |
|------|------|
| 姓名 | 访客姓名 |
| 电话 | 联系电话 |
| 公司 | 所属单位 |
| 职位 | 职务 |
| 车牌号 | 历史登记车牌 |
| 最近来访时间 | 最后到访时间 |

**复用逻辑**：勾选的访客数据自动填充到访客名单中。系统会校验添加后的总人数是否超过最大邀约人数，超限时提示管理员。

### 草稿箱

邀约表单支持保存为草稿，方便分次填写：

- **保存草稿**：填写过程中随时保存，草稿存入草稿箱
- **草稿箱列表**：展示草稿的访客姓名、访问类型、地点、保存时间
- **编辑草稿**：点击草稿的"编辑"按钮，草稿数据自动回填到邀约表单中
- **删除草稿**：从草稿箱中移除废弃的草稿

## 3.4.5 审批流配置

### 飞书审批联动

系统支持联动飞书审批流程进行访客申请审批，管理员在设置页面的"审批流"标签页下配置：

| 配置项 | 说明 |
|--------|------|
| 启用审批 | 总开关，关闭后访客邀约无需审批，直接进入待到访状态 |
| 飞书 AppId | 飞书企业自建应用的 App ID |
| 审批码 | 飞书审批定义编码，匹配对应的审批表单和流程 |
| 模板 ID | 飞书审批模板 ID |
| 审批人 | 审批人员列表（多选，从管理员列表中选择） |

**审批流程：**

```
员工提交访客邀约 → 平台生成审批单 → 推送至飞书审批
    │
    ├── 审批通过 → 回调平台 → 自动生成通行权限 → 发送通知给访客
    │
    └── 审批驳回 → 回调平台 → 状态标记为"异常" → 通知申请人
```

## 3.4.6 访客自助服务

### 访客自助添加同行人

访客在收到邀约短信后，可通过短信中的链接进入访客页面，自助添加同行人：

- 员工在发起邀约时设定访客总人数上限
- 访客点击短信链接进入 H5 页面
- 填写同行人的姓名、电话等信息
- 添加人数不超过员工设定的总人数上限
- 提交后平台自动更新访客名单，并为新增同行人生成通行权限

### 访客签到

系统支持两种签到方式：

**方式一：扫码签到**

- 访客到达园区后，在访客机或门禁处扫描预约码
- 系统验证预约信息，确认到访
- 签到的同时自动激活门禁通行权限
- 到访状态从"待到访"变更为"已到访"

**方式二：通行二维码**

- 访客通过邀约链接获取专属通行二维码
- 在门禁读卡器/人脸终端处展示二维码
- 扫码验证通过后开门，同时记录通行日志
- 通行二维码与到访时间段绑定，过期自动失效

### 通行二维码管理

管理员可在"通行二维码"页面（qrcode）中：

- 通过下拉选择框搜索并选择特定的访客申请
- 查看和复制该申请的访客通行链接
- 展示访客通行二维码（供现场打印或发送）

### 签到记录

系统记录所有访客签到信息，支持查询和追踪：

| 字段 | 说明 |
|------|------|
| 访客姓名 | 签到的访客姓名 |
| 公司 | 访客所属公司 |
| 签到时间 | 精确到秒的签到时间 |
| 签到方式 | 扫码签到 / 二维码通行 / 访客机登记 |
| 签到门禁点 | 签到发生的门禁设备名称 |
| 状态 | 已签到 / 未签到 |

## 3.4.7 提前结束行程

### 操作入口

管理员可在以下位置执行"提前结束行程"操作：

| 入口 | 说明 |
|------|------|
| PC 端访客列表 | 已到访状态的卡片上显示"结束行程"按钮 |
| PC 端运营管理 | 进行中状态的行程，操作下拉菜单中包含"结束行程" |
| 移动端 | 支持移动端管理员操作（统一 API） |

### 结束行程后处理

点击"结束行程"后，系统弹出二次确认对话框。确认后同步执行以下回收动作：

1. 访客状态变更为"已完成"
2. 门禁通行权限立即回收
3. 停车权限立即回收
4. 梯控权限立即回收
5. 生成离场记录
6. 向被访人发送访客离场通知（微信/短信）

| 待机主题 | 默认 / 深色 / 自定义 | 必填 |
| 待机页主图 | 图片上传（picture-card 组件） | 选填，支持预览 |

### 待机页样式管理

| 待机主题 | 说明 |
|----------|------|
| 默认 (default) | 系统预设的标准待机页样式 |
| 深色 (dark) | 深色风格的待机页 |
| 自定义 (custom) | 支持上传自定义主图，个性化展示园区信息和欢迎语 |

### 设备启停状态

| 状态 | 说明 |
|------|------|
| 在线 (active) | 设备正常运行，可进行访客登记 |
| 离线 (inactive) | 管理员停用设备，设备展示停用待机页，访客无法在此设备上登记 |

| 字段 | 说明 | 验证 |

支持将所有访客邀约、签到等记录导出为 Excel 报表，筛选条件与查询条件一致，导出结果发送至运营人员邮箱或直接下载。

## 3.4.10 邀约权限管理

### 权限管控模型

系统提供精细化的邀约权限管理，管理员在权限管理页面（permission）中配置：

**模式一：全员可邀约（默认）**

所有公司员工默认拥有访客邀约权限。通过排除机制关闭特定人员或部门的邀约权限：

| 排除维度 | 说明 |
|----------|------|
| 排除人员 | 远程搜索员工姓名，添加至排除列表。被排除的人员无法发起访客邀约 |
| 排除部门 | 选择部门（技术部/市场部/行政部/财务部/人事部/研发部），该部门下所有成员均不可邀约 |

**模式二：部分人员可邀约**

仅白名单内的人员和部门拥有访客邀约权限：

| 允许维度 | 说明 |
|----------|------|
| 允许人员 | 远程搜索并添加至允许列表（蓝色标签），仅列表内人员可发起邀约 |
| 允许部门 | 选择部门，该部门下所有成员可发起邀约 |

### 权限生效

- 权限配置保存后即时生效
- 无邀约权限的员工在前端不展示"发起邀约"入口
- 权限变更记录在审计日志中

## 3.4.11 通知设置

### 消息通知配置

管理员可在设置页面的"通知设置"标签页中配置访客全生命周期的消息通知：

| 通知场景 | 通知渠道 | 说明 |
|----------|----------|------|
| 访客邀请提醒 | 微信 / 短信（多选） | 向访客发送邀约通知，含通行链接 |
| 访客到访提醒 | 微信 / 短信（多选） | 访客签到后通知被访人 |
| 访客离场通知 | 微信 / 短信（多选） | 访客离场后通知被访人 |

### 通知模板

每种通知场景均支持自定义消息模板，运营人员可在文本域中编辑模板内容，支持变量占位符（如 `{访客姓名}`、`{到访时间}`、`{被访人}`、`{通行链接}`），发送时自动替换为实际数据。

### 增值服务

系统支持配置访客增值服务：

| 服务 | 说明 |
|------|------|
| 代客缴费 | 访客停车费用由被访人代缴 |
| 联动预定会议室 | 访客到访时自动为被访人预留会议室 |

## 3.4.12 访客统计仪表盘

### 数据概览卡片

访客统计页面（statistics）顶部以三张统计卡片展示核心数据，数字带滚动计数动画：

| 卡片 | 指标 | 说明 |
|------|------|------|
| 总邀请访客人数 | `invite_total` | 查询日期范围内的访客邀约总量 |
| 已到访客数量 | `visited_day_total` | 实际到访签到的访客数 |
| 未到访人数 | `novisit_day_total` | 已邀约但未签到的访客数 |

### 可视化图表

**访客分类饼图（环形图）**：

- 以环形饼图展示不同访问类型的占比
- 分类维度：预约访客 / 会务邀请
- 环形半径 40%-80%，圆角设计，白色边框

**24 小时访客量趋势图（折线图）**：

- 以平滑折线图展示 24 小时内各时段的访客流量
- X 轴：小时（0~23 时）
- Y 轴：访客数量
- 填充渐变区域，圆形数据点
- 支持 Tooltip 悬浮显示具体数值

## 3.4.13 访客详情与通行轨迹

### 访客详情抽屉

点击访客卡片"查看详情"打开 50% 宽度的详情抽屉（VisitorDetail），完整展示：

**基本信息网格（3 列布局）：**

| 字段 | 说明 |
|------|------|
| 申请编号 | 系统唯一编号 |
| 访客姓名 | 主访客姓名 + 状态标签 |
| 访问大楼 | 目标园区/楼栋 |
| 访问时间 | 到访起止日期时间 |
| 网络使用 | 需要 / 不需要 |
| 访问类别 | 业务合作 / 面试 / 其他 |
| 对接员工 | 内部被访人姓名 |
| 海外访客 | 是 / 否 |
| 访问事由 | 来访目的详细描述 |

**异常信息**：当状态为异常时，红色背景框展示异常原因。

**访客名单子表格**：展示每位同行访客的详细信息、到访状态（带颜色圆点）、到访时间。

### 通行轨迹

点击每位访客的"访客轨迹"按钮，弹出时间线弹窗（VistorFloowEdit），以 Timeline 组件按时间倒序展示该访客在园区内的通行轨迹：

- 每条轨迹记录包含：门禁点名称 + 通行时间
- 首条记录和出境记录以绿色高亮显示
- 数据来自门禁通行日志，每 30 秒自动轮询刷新

典型轨迹示例：
```
14:05 离开极企大厦（绿色-出境）
13:30 3F 办公区东门
12:05 1F 电梯
09:30 到达北门入口（绿色-首条）
```

### 评价结果

每位访客离场后可对访客体验进行评价。管理员在详情抽屉中点击"评价结果"按钮查看评分：

| 评价维度 | 说明 |
|----------|------|
| 设备设施满意度 | 1-5 星评分 |
| 接待人员满意度 | 1-5 星评分 |
| 文字评价 | 访客反馈文字内容 |

未评价时显示"暂无评价"占位。

## 3.4.14 开放 API 与模块联通

### 第三方系统集成

访客管理模块提供标准化 API 接口，支持与以下外部系统对接：

| 集成系统 | 接口说明 |
|----------|----------|
| 飞书审批 | 审批流创建、审批结果回调 |
| 短信平台 | 访客邀约短信、到访通知短信发送 |
| 微信通知 | 访客邀请模板消息、到访通知推送 |
| 企业 HR 系统 | 员工信息查询（对接人选择） |
| 第三方访客系统 | 通过 API 同步访客记录 |

### 平台内部模块联通

| 联通模块 | 集成方式 |
|----------|----------|
| 门禁管理 | 访客到访 → 自动下发门禁权限；访客离场 → 自动回收门禁权限 |
| 停车管理 | 访客车辆信息同步至停车系统，自动生成临时停车权限 |
| 梯控管理 | 访客自动获得目标楼层的电梯通行权限 |
| 工单系统 | 访客机设备故障 → 自动生成维修工单 |
| 会务系统 | 访客到访联动会议室预定 |

### API 接口清单

| 接口 | 方法 | 说明 |
|------|------|------|
| `/visitor/list` | GET | 访客申请列表（分页+状态筛选） |
| `/visitor/stat` | GET | 访客统计数据（总量+分类） |
| `/visitor/{id}` | GET | 访客申请详情 |
| `/visitor/range-trend` | GET | 24小时访客流量趋势数据 |
| `/visitor/getVisitTrack` | GET | 访客通行轨迹数据 |
| `/visitor/apply` | POST | 创建访客申请 |
| `/visitor` | DELETE | 批量删除访客申请 |

## 3.4.15 功能覆盖总结

### 标书要求对标

| 标书要求 | 对应模块 | 覆盖状态 |
|----------|---------|---------|
| (1) 邀约参数配置 | 设置页-邀请参数 Tab（maxInvitees/maxDays/earliestDays） | 100% |
| (2) 审批流配置 | 设置页-审批流 Tab（飞书 AppId/审批码/模板ID/审批人） | 100% |
| (3) 历史访客复用 | VisitorApply 历史访客选择弹窗（姓名/电话/公司搜索+勾选复用） | 100% |
| (4) 访客自助添加同行人 | 短信链接 H5 页面入口 + 员工预设总人数 + 自助添加 | 100% |
| (5) 提前结束行程 | PC 端访客列表+运营管理，结束行程后自动回收门禁/停车/梯控权限 | 100% |
| (6) 访客签到 | 扫码签到 + 通行二维码门禁通行（qrcode 模块） | 100% |

| (8) 运营管理 | Operation 模块（行程查询/结束/添加/登记/离场/移除访客/新建临时行程/报表导出） | 100% |
| (9) 邀约权限管理 | Permission 模块（全员可邀约+排除/部分人员可邀约，人员+部门双维度） | 100% |
