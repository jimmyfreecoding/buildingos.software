## 软件详细信息

### 硬件环境
- **软件开发硬件环境**：
  PC机：Intel Core i7或同等规格处理器，RAM≥16GB，硬盘≥512GB；开发阶段可使用NVIDIA GPU主机进行模型训练与转换。
- **软件运行硬件环境**：
  边缘推理主机：NVIDIA Jetson Orin Nano（8GB统一内存，67 TOPS，JetPack 6.x）或同等边缘GPU设备，NVMe SSD≥256GB。
  摄像机：PoE网络摄像机，1080p/H.265编码，支持RTSP推流，每台边缘主机接入8-16路。
  流媒体服务：ZLMediaKit容器，负责RTSP/RTMP流转发与截图。
  网络与供电：千兆交换机、PoE供电（如需）、UPS≥1KVA。
  管理终端：PC/平板浏览器，访问Web管理界面。

- **开发该软件的操作系统**：Linux（Ubuntu 22.04）/ Windows 11 / macOS 14

### 开发目的
- **内容**：实现楼宇办公区视频AI感知与节能联动控制。

### 面向领域/行业
- **内容**：智慧楼宇、园区AI视觉感知与节能管理行业。

### 软件主要功能
- **内容**：
  本软件实现基于边缘AI的楼宇空间感知与节能联动，包括多路摄像头流接入与管理（RTSP/RTMP）、吸烟行为实时检测与告警、办公区人员存在感知与占用检测、多路画面空间融合与时段权重融合判定、遮挡场景下的存在记忆与微动检测、无人消抖定时节能联动（灯光调暗/关闭、空调关闭）、推理参数在线配置、人员占用热力图与历史日志查询、本地大模型复核、系统资源监控与远程运维。

### 软件主要技术特点
- **分类**：人工智能软件 物联网软件 智慧城市软件
- **详细说明**：
  采用YOLO/RF-DETR模型TensorRT量化加速的边缘推理架构；多路RTSP流经ZLMediaKit统一接入并采用子码流抽帧策略降低解码压力；基于目标跟踪与人体姿态估计实现静态物体误报过滤；Node-RED业务编排实现空间融合、时段权重与消抖决策；MQTT协议实现检测结果与照明空调联动指令下发；Web管理端支持参数配置、热力图查询与本地多模态大模型复核。
