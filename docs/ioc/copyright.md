- **内容**：智慧楼宇、园区运营管理、综合态势感知与可视化监控行业。

### 软件主要功能
- **内容**：
  本软件实现园区运营中心综合态势感知与可视化监控，包括六大功能看板：安防看板（今日告警/待处理/在线摄像头/离线摄像头/安保人员/巡逻路线六项统计卡片，摄像头状态列表，24小时告警趋势柱状图与折线图组合，告警类型环形饼图，最近安全事件列表）；告警看板（多维筛选栏支持日期范围/级别/状态/区域/类型五维度组合过滤，总告警/已处理/处理中/未处理/响应率/平均响应六维统计概览，近7日告警趋势柱状图与折线图组合，告警来源横向柱状图，区域分布环形饼图，分页告警事件列表支持前端内存筛选）；通行看板（今日车流量/车位占用率含环形进度条/在园人数/今日访客四项统计卡片，车流量趋势入场出场分组柱状图，各区域人员密度水平渐变色横向柱状图，车位使用情况环形图与分区进度条，最近车辆通行记录表格）；环境看板（温度/湿度/AQI/PM2.5/CO₂/TVOC/噪音/舒适度八项指标卡片，舒适度指数前端七维度加权计算，各区域温度趋势平滑折线图含渐变面积填充，环境传感器详情表格含进度条可视化与异常高亮提示）；餐厅看板（当前就餐人数/座位占用率含SVG环形进度图/今日用餐总数/平均排队时间/高峰时段/总座位数六项统计卡片，就餐趋势柱状图含高峰时段渐变着色与趋势线，各区域就餐分布双系列叠加柱状图，今日菜单排序表格含评分组件，本周各餐次统计分组柱状图）；会议看板（今日会议数/进行中含脉冲动画圆点/会议室使用率/参会总人数/待开会议/平均时长六项统计卡片，会议室实时状态双列网格含四种状态彩色边条，部门会议使用统计横向柱状图，当前进行会议列表，本周会议趋势双Y轴组合图）。所有数据当前采用前端Mock模拟，通过统一延迟函数模拟300ms网络响应，各看板采用Promise.all并行加载模式。

### 软件主要技术特点
- **分类**：智慧城市软件 企业管理软件 数据可视化软件
- **详细说明**：
  采用Vue3+TypeScript+Vite纯前端单页应用架构，Vue 3 Composition API统一编码风格，defineOptions显式声明组件名称；ECharts 5可视化引擎通过vue-echarts的<v-chart>组件封装，按需注册CanvasRenderer渲染器、BarChart/LineChart/PieChart图表类型及Title/Tooltip/Legend/Grid交互组件，所有图表支持autoresize自适应容器尺寸；Element Plus组件库提供el-row/el-col栅格布局、el-card卡片容器、el-table数据表格、el-tag状态标签、el-progress进度条、el-rate评分、el-form表单、el-date-picker日期选择器、el-select下拉选择等UI组件；Vab框架组件提供vab-card统一卡片容器、vab-query-form查询表单、vab-pagination分页组件；统一设计语言采用白色卡片+彩色左边框(border-left:4px solid)+8px圆角+阴影，悬停时阴影加深或上移动效；Mock数据层统一使用mock()工具函数封装300ms延迟Promise，支持前端内存筛选与分页逻辑；环境看板舒适度引擎按温度(22°C最佳)、湿度(50%最佳)、噪音(45dB最佳)等七维度加权计算0-100分综合指数；餐厅看板高峰时段判定引擎通过字符串比较识别11:30-12:30午间高峰区间并切换柱状图渐变着色；通行看板车位分区统计算法按比例缩放总车位数据至四分区展示；会议看板双Y轴组合图同步展示会议数量（柱状图左轴）与使用率（折线图右轴百分比）；所有看板采用height:100vh配合overflow-y:auto的全高度滚动布局，背景色统一#f0f2f5，统计卡片使用等宽数字字体(tabular-nums)确保数值变化无布局抖动。
