# 软件著作权登记申请表 — 填写规范

> 本文档为版权局《计算机软件著作权登记申请表》中各项字段的填写规范说明。实际输出文件为每个系统目录下的 `copyright.md`。

---

## 一、填写须知

1. 企业办理软件著作权需提供：本数据采集表、已年检营业执照副本复印件（盖章）、鉴别材料（源程序及使用说明书）。
2. 软件名称格式要求：`××××软件` 或 `××××系统` 或 `××××平台`。
3. 版本号格式：`V1.0`、`V1.2`、`V2.0` 等。
4. 开发完成日期必须在公司成立日期之后。用于申报高新技术企业时，完成时间应为近三年内。
5. 著作权的"发表"是指公开的意思，不同于出版意义的发表。
6. 功能和特点总字数要求 300 字以内。

---

## 三、字段填写说明

### 软件基本信息

| 字段 | 要求 |
|------|------|
| 软件全称 | 格式 `××××系统` 或 `××××软件`，以"智能楼宇"开头统一前缀 |
| 软件简称 | 格式 `Buildingos.xxx`，全小写英文，与代码仓库名一致 |
| 版本号 | 统一使用 `V1.0` |
| 软件作品说明 | 固定填写 `原创` |

### 辅助信息

| 字段 | 要求 |
|------|------|
| 开发完成日期 | 晚于公司成立日期（2014年之后），如有高新申报需求应为近三年内 |
| 发表时间 | 晚于开发完成日期，一般间隔 1 个月 |
| 发表城市 | 成都 |
| 开发方式 | 独立开发 |

### 软件详细信息 — 硬件环境

**软件开发硬件环境**（统一模板，不必修改）：
> PC机：Intel Core i7或同等规格处理器，RAM≥16GB，硬盘≥512GB。

**软件运行硬件环境**：按系统实际情况逐项列出，每类设备给出 CPU / RAM / 存储规格。常见分类：
- 服务端 / 云主机
- 边缘网关
- 终端设备（Pad / 一体机 / 自助机）
- 传感器与控制器
- 网络与供电设备

### 软件详细信息 — 软件环境

**开发环境**（统一模板，不必修改）：
> Node.js 20.x、Vite、Vue 3、TypeScript 5.x、NestJS 10.x、pnpm/npm

**运行环境**（统一模板）：
- 操作系统：Linux（Ubuntu 22.04）
- 中间件：Nginx、PostgreSQL 15、Redis 7、MQTT Broker（EMQX/Mosquitto）、Docker

### 软件详细信息 — 功能与技术特点

| 字段 | 字数限制 | 编写要点 |
|------|----------|----------|
| 开发目的 | ≤50字 | 一句话说明软件要解决什么问题，动词开头（实现/规范/统一） |
| 面向领域/行业 | ≤50字 | 格式：智慧楼宇、{细分}行业 |
| 软件主要功能 | ≤200字 | 分号分隔 4-6 项核心功能，每项包含"能力+价值" |
| 技术特点详细说明 | ≤100字 | 列出 3-4 项技术特征：前端框架+后端框架+协议+安全/可靠机制 |

## 四、源代码规范

1. 全部源代码不足 3000 行的需提供全部源代码。
2. 源代码超过 3000 行的，提供源程序全部代码的连续前 1500 行和连续后 1500 行。或以每页≥50行、连续前30页和连续后30页的形式提交。
3. 源代码应提供可编辑的 WORD 版本或在 Markdown 中用代码块包裹，不能带框、不能带图片。
4. **源代码中不得出现公司名称、个人名称、文件名称**。

## 五、其他材料清单

### 营业执照
申请人营业执照应有当年的年检章（新领执照除外，包括新成立公司或做过企业变更的执照）。

### 实名认证（格式：jpg/png/jpeg）
**公司名义申请**：
1. 申请公司营业执照副本清晰彩色扫描件（不盖章）
2. 联系人（同申请表中联系人）身份证正反面清晰彩色扫描件（可拍照，但不能出现反光变形等情况）
3. 授权书盖章扫描件

**个人名义申请**：
1. 申请人身份证正反面清晰彩色扫描件
2. 申请人手持身份证清晰照片

### 注意事项
- 提供联系人手机号码和邮箱用于实名认证时的验证，手机号码后续用于查看电子证书。
- 申请人认证时间：1-3 工作日。
- 如果证明文件需要加水印，必须是："仅供办理中国版权保护中心各项申请使用"，不能加其他字眼。
