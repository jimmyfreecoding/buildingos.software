## 1. 引言

### 1.1 编写目的
本操作说明书旨在详细阐述《智能工位管理系统 buildingos.workstation》的功能架构、操作流程及维护方法。文档面向系统管理员、行政管理人员及空间运营人员，提供标准化的操作指引，帮助用户快速掌握工位大屏可视化、共享工位预定、固定工位分配、地图管理及统计分析等核心功能的使用方法，确保工位资源的高效利用与精细化管理。

### 1.2 定义
*   **系统/本系统**：指《智能工位管理系统 buildingos.workstation》。
*   **固定工位**：指长期分配给特定员工使用的工位，通过人员绑定关系实现一对一归属。
*   **共享工位**：指不固定归属、可按日期和时间段预定的工位，适用于灵活办公场景。
*   **工位标记**：指三维室内地图上以彩色圆形图标叠加显示的工位标识，颜色反映工位实时状态。
*   **感应释放**：指通过人体红外/微波传感器检测到工位无人后，系统自动将工位状态变更为空闲的机制。
*   **空间编码**：指楼宇内楼层、区域、房间等空间单元的唯一标识码，用于工位坐标定位和地图关联。

## 2. 系统概述

### 2.1 系统用途
《智能工位管理系统 buildingos.workstation》是专为现代化智慧楼宇和园区打造的工位资源管理平台。系统以 AirocovMap 三维室内地图为可视化载体，将工位资源在真实楼层平面图上以彩色标记叠加展示，支持固定工位的全生命周期管理（分配、收回、批量调整）、共享工位的按日期时段在线预定及冲突检测，并通过物联网传感器实现工位占用状态的实时同步与自动释放。系统同时提供工位使用率、预定趋势和部门分布等多维度统计分析，为办公空间规划与资源优化提供数据支撑。

### 2.2 软件功能概述
本系统主要包含以下核心功能模块：
1.  **工位大屏可视化**：以三维室内地图为核心，在楼层平面图上以颜色编码标记展示工位空闲/占用/维修中状态，支持楼层切换、工位定位飞行、分配释放等一站式操作。
2.  **共享工位预定**：支持按日期和时间段在线预定共享工位，内置时间段冲突检测算法，可联动门禁系统自动下发与回收通行权限。
3.  **固定工位管理**：提供固定工位的列表查询、单个分配/收回和批量分配功能，支持按工位编号、部门、状态组合筛选。
4.  **地图管理**：维护工位地图与楼栋、楼层的关联关系，管理地图的启用状态。
5.  **工位统计分析**：以摘要卡片、折线图和环形图展示工位使用率、预定趋势和部门分布，辅助管理决策。

### 2.3 软件运行环境
*   **硬件环境**：
    *   **服务端**：推荐 Intel Xeon 8核以上处理器，16GB 内存，512GB SSD 存储。
    *   **客户端**：普通办公PC（i5/8GB/256GB），建议屏幕分辨率 1920x1080 以上。
    *   **物联网外设**：人体红外/微波传感器、智能平板终端（可选），通过 Zigbee/Wi-Fi/RS-485 接入边缘网关。
*   **软件环境**：
    *   **服务端操作系统**：Linux (Ubuntu 20.04+) 或 Windows Server 2019。
    *   **数据库**：PostgreSQL 15 / MySQL 8.0 / SQLite（自适应切换）。
    *   **运行依赖**：Docker、Nginx、Node.js 20.x 环境。
    *   **浏览器**：Google Chrome 80+、Microsoft Edge 或 Firefox。

### 3.1 登录与首页

系统采用B/S架构，用户通过浏览器访问指定URL即可进入登录页面。
*   **操作步骤**：
    1.  在浏览器地址栏输入系统访问地址。
    2.  进入登录页后，输入分配的用户名和密码。
    3.  点击"登录"按钮，系统进行JWT身份验证，验证通过后跳转至系统首页。
*   **界面展示**：

### 3.2 工位大屏可视化

#### 3.2.1 三维地图浏览与楼层切换
工位大屏是系统核心可视化界面，以 AirocovMap 三维室内地图为载体，将工位资源在楼层平面图上以彩色圆形标记叠加展示。
*   **功能说明**：
    *   **楼层选择器**：页面顶部提供楼层下拉选择框，加载当前空间的所有楼层列表。切换楼层后，三维地图自动飞行定位到对应楼层平面图并加载该楼层的工位标记。
    *   **刷新按钮**：选择器旁提供刷新按钮，支持手动更新地图上的工位状态数据。
    *   **三维地图区域**：占据页面约 70% 宽度，使用 AirocovMap 引擎渲染。地图支持鼠标拖拽平移和滚轮缩放，左下角提供 3D/2D 模式切换按钮和指北针控件。
    *   **工位标记**：每个工位以 Canvas 生成的 36px 直径圆形标记叠加显示在地图对应坐标位置。标记颜色根据工位当前状态动态渲染——空闲绿色（#67C23A）、占用红色（#F56C6C）、维修橙色（#E6A23C）。标记边缘使用白色描边增强可见性。
    *   **飞行定位**：点击工位列表中的"定位"按钮，地图摄像机自动执行飞行动画，平滑移动到目标工位空间位置并高亮选中。
    *   **工位弹窗**：点击地图上的工位标记，弹出信息窗口展示工位编号、当前状态和使用人姓名。
*   **操作步骤**：
    1.  在顶部楼层下拉框中选择目标楼层（如"1F"）。
    2.  等待地图自动加载该楼层的平面图和工位标记。
    3.  使用鼠标拖拽平移地图，滚轮缩放查看不同区域的工位分布。
    4.  点击工位标记查看该工位详细信息。
    5.  点击左下角按钮可在 3D/2D 模式之间切换视角。
*   **界面展示**：
    ![工位大屏地图](image-2.png)
    *图 3-3 工位大屏三维地图展示*

#### 3.2.2 统计卡片与状态图例
楼层选择器下方展示四个可点击的统计卡片，点击后自动筛选对应状态的工位列表。
*   **功能说明**：
    *   **总工位**（蓝色卡片）：当前楼层或全空间的工位总数，点击显示全部工位。
    *   **空闲工位**（绿色卡片）：当前处于空闲状态的工位数量，点击后仅显示空闲工位。
    *   **已占用**（红色卡片）：当前处于占用状态的工位数量，点击后仅显示已占用工位。
    *   **使用率**（橙色卡片）：已占用工位数占总工位数的百分比（已占用 / 总数 × 100%），直观反映空间利用效率。
    *   **图例栏**：统计卡片下方展示统一图例栏，以四种颜色圆点和文字标注区分空闲、占用、维修中、已选中四种状态，地图上所有工位标记颜色与图例严格对应。
*   **界面展示**：
    ![统计卡片与图例](image-3.png)
    *图 3-4 统计卡片与状态图例*

#### 3.2.3 工位列表筛选与详情
右侧面板使用选项卡布局，第一个选项卡为"工位列表"。
*   **功能说明**：
    *   **状态筛选**：列表上方提供筛选按钮组（全部/空闲/占用/维修中），点击后列表仅展示对应状态的工位。
    *   **列表项信息**：每项展示状态颜色圆点、工位编号（如"A-1F-001"）、位置描述文字、状态标签（绿色成功/红色危险/橙色警告）、使用人姓名（占用状态下显示）。
    *   **操作按钮**：每行提供"定位"按钮（地图飞行定位到该工位）、"分配"按钮（空闲状态下可见，打开分配弹窗）、"释放"按钮（占用状态下可见，释放工位为空闲）。
*   **界面展示**：
    ![工位列表](image-4.png)
    *图 3-5 右侧工位列表面板*

#### 3.2.4 工位分配与释放操作
点击"分配"按钮弹出分配弹窗（约 500px 宽），用于将空闲工位分配给指定人员。
*   **功能说明**：
    *   **工位编号**：自动填充目标工位编号，不可编辑。
    *   **分配人员**：可搜索下拉选择，从预设人员列表中选择分配对象。
    *   **所属部门**：可搜索下拉选择（如研发部、产品部、设计部、市场部、行政部、运营部）。
    *   **释放操作**：点击已占用工位的"释放"按钮，弹出确认对话框，确认后工位状态恢复为空闲，清除使用人和部门信息。
*   **操作步骤**：
    1.  在工位列表中找到目标空闲工位，点击"分配"按钮。
    2.  在弹窗中选择分配人员和所属部门。
    3.  点击"确认分配"，工位状态变更为已占用。
    4.  如需释放，点击已占用工位的"释放"按钮，确认后完成释放。
*   **界面展示**：
    ![分配弹窗](image-5.png)
    *图 3-6 工位分配弹窗*

#### 3.2.5 快速操作面板
右侧面板的第二个选项卡为"快速操作"，提供批量操作和楼层概况入口。
*   **功能说明**：
    *   **一键预定最近空闲工位**：自动查找当前楼层第一个空闲工位，为当前用户执行预定操作。
    *   **批量释放当前楼层**：将当前楼层的所有已占用工位批量释放为空闲状态，适用于大规模工位调整场景。
    *   **楼层摘要**：以描述列表展示当前楼层的工位概况——总工位数、空闲数量、占用数量、维修中数量。
*   **操作步骤**：
    1.  点击"快速操作"选项卡。
    2.  点击"一键预定最近空闲工位"按钮，系统自动查找并确认预定。
    3.  如需批量释放，点击"批量释放当前楼层"按钮，确认后执行。
*   **界面展示**：
    ![快速操作面板](image-6.png)

### 3.3 共享工位预定

#### 3.3.1 在线预定
共享工位预定模块以两个选项卡组织在线预定和预定管理功能。
*   **功能说明**：
    *   **日期选择**：页面顶部提供日期选择器，选择预定目标日期。点击"查询可用工位"按钮后，系统加载该日期可预定的共享工位列表。
    *   **工位卡片网格**：可用工位以响应式卡片网格（每行 4 列）展示。每张卡片包含：工位编号、状态标签（空闲绿色/已预定灰色）、位置描述、设施标签（如"靠窗""双屏""静音区"）、预定按钮或下次可用提示。
    *   **设施标签**：工位支持添加特色标签，方便预定人员根据偏好选择工位。
    *   **预定弹窗**：点击"预定"按钮后弹出预定弹窗，配置工位编号（只读）、时间段（开始/结束时间，范围 08:00-20:00，30 分钟步长）和预定人姓名。
    *   **冲突检测**：提交时系统实时检测时间段是否与已有预定重叠（时间区间相交判定），避免同一工位同一时段被重复预定。若当前时间已在预定时段内，自动将该工位状态更新为占用。
    *   **门禁联动**：预定成功后，系统可配置是否自动向预定人下发对应空间区域的门禁通行权限，权限有效期与预定时间段一致，预定结束后自动回收。
*   **操作步骤**：
    1.  在日期选择器中选择目标日期。
    2.  点击"查询可用工位"按钮，系统展示可用工位卡片。
    3.  浏览工位卡片，根据设施标签和位置选择合适的工位。
    4.  点击空闲工位卡片上的"预定"按钮。
    5.  在弹窗中选择时间段（如 09:00-12:00），填写预定人姓名。
    6.  点击确认提交预定，系统自动执行冲突检测并创建预定记录。
*   **界面展示**：
    ![在线预定](image-7.png)
    *图 3-8 共享工位在线预定*

#### 3.3.2 预定管理
预定管理选项卡以表格形式展示所有预定记录。
*   **功能说明**：
    *   **查询筛选**：顶部查询栏支持按预定人姓名筛选。
    *   **表格列**：包含订单号、工位编号、预定人、部门、开始时间、结束时间、状态（活跃/已完成/已取消）和操作按钮。
    *   **取消预定**：仅活跃状态的预定显示"取消"按钮。取消预定时若当前时间在预定时段内，系统自动将工位状态释放为空闲，同时回收已下发的门禁权限。
*   **操作步骤**：
    1.  点击"预定管理"选项卡切换视图。
    2.  在查询栏输入预定人姓名（可选），点击"查询"按钮。
    3.  查看预定记录列表。
    4.  对需要取消的活跃预定，点击"取消"按钮执行取消操作。
*   **界面展示**：
    ![预定管理](image-8.png)
    *图 3-9 预定记录管理列表*

### 3.4 固定工位管理

*   **操作步骤**：
    1.  在查询栏输入工位编号或部门关键字。

    3.  点击"查询"按钮，表格加载符合条件的工位列表。
*   **界面展示**：
    ![固定工位列表](image-9.png)
    *图 3-10 固定工位管理列表*

#### 3.4.2 单个分配与收回
对单个工位执行人员分配或收回操作。
*   **功能说明**：
    *   **分配弹窗**：点击"分配"按钮弹出分配弹窗，填写部门（文本输入）和使用人（文本输入）。确认后工位状态变更为已占用。
    *   **收回操作**：已占用的工位行显示"收回"按钮，点击后弹出确认对话框。确认后工位状态恢复为空闲，清除使用人和部门信息。
*   **操作步骤**：
    1.  点击目标工位行的"分配"按钮。
    2.  在弹窗中填写部门和使用人信息。
    3.  点击确认完成分配。
    4.  如需收回，点击"收回"按钮并在确认对话框中确认。
*   **界面展示**：
    ![固定工位分配](image-10.png)
    *图 3-11 固定工位分配弹窗*

#### 3.4.3 批量分配
通过勾选多行实现一次性批量分配工位，适用于部门统一分配场景。
*   **功能说明**：
    *   **多选**：表格首列提供多选框，可勾选多个工位。
    *   **批量分配弹窗**：点击"批量分配"按钮后弹出弹窗，标题栏显示选中工位数量（如"批量分配 (5 个)"）。填写统一的部门和使用人信息后，系统批量更新所有选中工位。
*   **操作步骤**：
    1.  勾选表格中需要分配的目标工位（可多选）。
    2.  点击"批量分配"按钮。
    3.  在弹窗中填写部门和使用人。
    4.  点击确认，系统一次性更新所有选中工位。
*   **界面展示**：
    ![批量分配](image-11.png)
    *图 3-12 批量分配操作*

### 3.5 地图管理

#### 3.5.1 地图列表查询
地图管理页面用于维护工位地图的基础信息。
*   **功能说明**：
    *   **查询栏**：支持按地图名称关键字搜索，右侧提供"新增地图"按钮。

#### 3.5.2 新增与编辑地图
弹出表单弹窗用于创建或修改工位地图信息。
*   **功能说明**：
    *   **地图名称**（必填）：文本输入，如"A栋 2F 工位平面图"。
    *   **所属楼宇**：文本输入，关联的楼栋名称。
    *   **楼层**：文本输入，关联的楼层编号。
    *   **状态**：开关组件，控制地图启用或停用。
    *   **设计地图**：为地图设计器的预留入口，点击后提示进入设计器，后续可扩展为可视化工位平面图编辑器。
    *   **删除**：删除时弹出确认对话框，防止误操作。
*   **操作步骤**：
    1.  点击"新增地图"按钮，弹出空白表单。
    2.  填写地图名称、所属楼宇、楼层信息。
    3.  设置启用状态开关。
    4.  点击保存，地图信息写入数据库。
    5.  如需编辑，点击表格中目标行的"编辑"按钮修改信息。

### 3.6 工位统计分析

#### 3.6.1 摘要统计卡片
工位统计看板以四个摘要卡片和 ECharts 图表展示工位资源使用情况和部门分布。
*   **功能说明**：
    *   **总工位**：系统中所有工位的总数。
    *   **当前占用**：当前处于占用状态的工位数量。
    *   **今日预定**：当日共享工位的预定数量（取当天预定趋势的最后一个数据点）。
    *   **今日感应释放**：当日通过人体传感器检测无人后自动释放的工位数量。

#### 3.6.2 预定趋势与部门分布
通过 ECharts 图表直观展示预定趋势和各部门资源占用情况。
*   **功能说明**：
    *   **预定趋势图**（左侧 50% 宽度）：折线图展示最近 7 天每日预定数量趋势。X 轴为日期，Y 轴为预定数。折线为平滑曲线，曲线下方使用半透明渐变填充。鼠标悬浮显示详细 tooltip（日期 + 预定数）。图表自适应容器尺寸变化。
    *   **部门使用分布**（右侧 50% 宽度）：环形图展示各部门占用的工位数量分布。环形内径 40%、外径 70%，各扇区以白色间隙分隔，边缘圆角化。图例居中展示在图表上方。数据按部门维度分组统计，直观对比各部门工位资源分配情况。
