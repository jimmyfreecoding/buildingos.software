# 3.11 信息发布

## 需求概述

本系统提供覆盖多媒体素材管理、投放排期与审批、设备分组监控和系统配置全流程的一体化信息发布管理解决方案。系统以"素材 → 投放 → 审批 → 设备"为业务主线，支持视频、多屏、网页、直播四种内容类型的投放，支持每天、每周、单次、自定义四种排期模式，内置多级审批流程和基于设备数量的风险等级自动评估，并通过园区隔离机制实现多园区间的数据安全隔离。

---

## 3.11.1 整体架构

### 模块总览

信息发布管理系统包含四个功能模块，通过左侧菜单树组织：

**素材管理**——以分类树和素材网格双栏布局管理图片、视频等多媒体素材，支持自定义分类、拖拽上传、批量删除和素材预览。

**投放管理**——包含投放排期和审批管理两个子模块，支持视频/多屏/网页/直播四种内容类型的投放配置，支持每天/每周/单次/自定义四种排期模式。

**设备管理**——支持按区域和设备类型进行分组管理，提供列表和卡片双视图模式，实时监控设备在线状态和心跳，支持远程重启操作。

**系统配置**——提供设备类型管理、流程实例配置、审批流配置和园区隔离四项系统级配置能力。

### 技术架构

信息发布管理系统拥有独立的 NestJS 后端微服务（端口 3036），支持 Docker 独立部署或嵌入主进程（NPM_INSTALL 模式）。后端提供完整的 REST API 和 Swagger 文档（`/publish/docs`），通过 MQTT 协议实现微服务间通信和健康检查。前端使用 Vue 3 + TypeScript + Element Plus 构建，API 层基于 Axios 封装，采用 JWT 统一认证。

## 3.11.2 素材管理

### 功能入口

信息发布 → 素材管理

### 功能描述

素材管理以左右分栏布局组织，左侧为分类导航树，右侧为素材网格展示区，支持图片和视频两类多媒体素材的上传、组织、分类和预览。

#### 分类管理

左侧分类树包含系统预置分类和用户自定义分类两个区域。

**系统预置分类**固定包含"全部素材""图片""视频"三个节点，点击后按对应类型过滤右侧素材列表。每个分类节点旁显示该分类下的素材数量。

**自定义分类**区域以分隔线与系统分类区分，支持用户根据业务需要创建个性化分类。点击底部的"+"按钮弹出新增分类弹窗，配置分类名称（必填，最长 20 字符）和素材类型（图片/视频）。分类名称支持通过顶部的即时搜索框进行过滤，便于在大量分类中快速定位。每个自定义分类节点悬停时显示删除按钮，删除前弹出确认对话框防止误操作。

#### 素材上传

点击"上传素材"按钮打开上传弹窗。上传区域支持拖拽或点击选择文件，支持 PNG、JPEG 图片和 MP4 视频格式，每次上传一个文件。选中文件后显示为可关闭的标签，表单需填写素材分类（从自定义分类下拉选择）和素材标题（可选，最长 100 字符，留空则自动使用文件名）。

系统自动检测上传文件的类型（图片/视频）并计算文件大小（MB），保存后素材进入对应分类。

#### 素材网格

右侧素材网格以响应式卡片布局展示素材，自适应不同屏幕宽度。每张素材卡片包含：

**媒体预览区**（160px 高）——图片素材使用 el-image 组件展示封面缩略图，视频素材以渐变背景和视频占位图标展示。悬停时图片缩略图放大，视频显示播放按钮覆盖层。卡片右上角显示类型标签（图片/视频）。

**信息区**——展示素材标题（单行溢出省略）、文件大小和分辨率等元数据、所属分类标签和上传者名称。

卡片左上角提供复选框用于批量选择，底部删除按钮在选中素材后激活，支持批量删除。

#### 素材预览

点击任意素材卡片打开预览弹窗。图片素材使用图片查看器组件，支持缩放操作。视频素材显示文件信息的占位预览。预览弹窗底部以描述列表展示素材的完整元数据：名称、类型、大小、分辨率、分类、上传者、上传时间。

列表为空时展示空状态提示（el-empty），引导用户上传素材。

## 3.11.3 投放管理

### 投放排期

#### 功能入口

信息发布 → 投放管理 → 投放排期

#### 功能描述

投放排期以列表形式管理所有投放任务，支持新建、编辑、删除和提交审批操作。

##### 列表筛选

顶部查询栏支持按投放状态（全部/草稿/待审批/待发布/发布中/已结束）、内容类型（全部/视频/多屏/网页/直播）和投放名称关键字组合筛选，右侧提供查询和重置按钮。

##### 投放列表

数据表格包含以下列：序号、复选框、投放名称、内容类型（以不同颜色的 el-tag 标识：视频蓝色、多屏绿色、网页橙色、直播红色）、投放设备数（支持排序）、排期模式、开始日期、结束日期、状态（草稿灰色、待审批橙色、待发布蓝色、发布中绿色、已结束默认色）、创建人、创建时间。每行操作列提供编辑和删除按钮，草稿状态的投放额外显示"提交审批"按钮。

##### 新建/编辑投放

点击"新建投放"按钮打开配置弹窗（宽度 750px），分区域配置：

**基本信息**——投放名称（必填，最长 50 字符，显示字数统计）和内容类型（必填：视频/多屏/网页/直播）。

**内容配置**（根据内容类型动态切换）：
- 视频：视频文件上传器，支持 MP4/AVI/MOV/MKV 格式，建议最大 500MB
- 多屏：数字输入选择屏幕数量（2-16 屏），用于多屏组合展示场景
- 网页：URL 文本输入框，填写待投放的网页地址
- 直播：直播流 URL 文本输入框（如 rtmp://协议地址）

**排期配置**——以单选按钮组选择排期模式：
- **每天模式**——设置每日的投放时间段（开始时间至结束时间，HH:mm 格式）。适用于日常循环播放场景，如企业宣传片每日 09:00-18:00 循环播放
- **每周模式**——勾选投放的星期（周一至周日复选框组），设置每日的投放时间段。适用于工作日的周期性内容投放
- **单次模式**——选择特定日期，设置当日的投放时间段。适用于一次性活动通知或临时公告
- **自定义模式**——多选日期（支持不连续的多个日期），设置统一的投放时间段。适用于不规则的展会、活动日程安排

**投放范围**——投放区域通过树形选择器从区域树中选择（支持多选），目标设备通过多选下拉列表选择具体设备。此两级选择实现精准的投放范围控制。

**有效期限**——日期范围选择器，设置投放的起始日期和截止日期，超出期限后投放自动失效。

**风险等级**——系统根据目标设备数量自动评估风险等级并以彩色标签展示：全部设备为高风险（红色）、超过 5 台设备为中风险（橙色）、5 台及以内为低风险（绿色）。界面显示对应的计算规则说明，帮助运营人员预判投放的影响范围。

**创建后提交审批**——提供"创建后提交审批"复选框，勾选后保存并自动提交至审批流程。

---

### 审批管理

#### 功能入口

信息发布 → 投放管理 → 审批管理

#### 功能描述

审批管理对投放任务进行审批流程控制，确保投放内容的安全性和合规性。

##### 审批列表

顶部查询栏支持按审批状态（全部/待审批/已通过/已驳回）、风险等级（全部/低/中/高）和投放名称/申请人关键字组合筛选。

数据表格（斑马纹样式）包含以下列：序号、投放名称、申请人、申请时间、内容类型（彩色标签）、排期模式、投放范围、风险等级（彩色标签）、审批状态（彩色标签）。待审批状态的记录操作列显示"审批"按钮，所有记录均显示"详情"按钮。

##### 审批操作

点击"审批"按钮打开审批对话框，展示投放的完整详情：

**投放详情**——以双列描述列表展示投放名称、申请人、申请时间、内容类型、排期详情、投放范围、风险等级和审批状态。

**审批操作区**——审批意见文本框（最长 500 字符，显示字数统计），驳回时意见为必填。底部提供"通过"（绿色按钮）和"驳回"（红色按钮）两个操作按钮，点击后弹出二次确认对话框防止误操作。

##### 详情查看

点击"详情"按钮查看审批的完整记录。已审批的记录额外展示审批结果标题、审批结果标签（已通过绿色/已驳回红色）、审批人姓名、审批时间和审批意见内容。

## 3.11.4 设备管理

### 功能入口

信息发布 → 设备管理

### 功能描述

设备管理以分屏布局（左右比例 4:20）组织，左侧为区域树，右侧为设备列表区，支持按区域和设备类型进行分组管理。

#### 区域树与统计

左侧区域树支持搜索过滤、展开全部和高亮当前节点。每个区域节点旁显示该区域的设备数量标签。点击区域节点后右侧设备列表自动过滤。

右侧顶部展示四个统计卡片（每行四列）：
- **总设备数**（蓝色卡片）——当前筛选范围内的设备总数
- **在线设备数**（绿色卡片）——当前处于在线状态的设备数量
- **离线设备数**（红色卡片）——当前处于离线状态的设备数量
- **离线率**（橙色卡片）——离线设备数占总设备数的百分比

四个卡片的数值随区域筛选和类型筛选动态重新计算。

#### 设备筛选

统计卡片下方提供设备筛选栏：
- 设备类型筛选（单选按钮组）：全部 / LED大屏 / 广告屏 / 信息屏 / 触摸一体机 / 电子水牌
- 在线状态筛选（单选按钮组）：全部 / 在线 / 离线
- 关键字搜索（文本输入）：按设备名称或 IP 地址搜索
- 视图切换（单选按钮组）：列表模式 / 卡片模式

#### 列表模式

数据表格展示设备信息：序号、设备名称、设备类型（彩色标签，LED大屏红色、广告屏橙色、信息屏蓝色、触摸一体机绿色、电子水牌灰色）、所属区域、楼层、IP 地址、分辨率、在线状态（绿色圆点在线 / 红色圆点离线）、最后心跳时间。每行操作列提供"重启"和"编辑"按钮。

#### 卡片模式

设备以响应式卡片网格展示，自适应屏幕宽度。每张卡片包含：

**顶部**——设备名称 + 在线状态标签（带状态圆点），设备类型标签。

**内容区**——IP 地址、分辨率、所属区域和楼层、最后心跳时间。

**底部**——重启和编辑操作按钮。

卡片左边框以颜色编码：绿色表示在线，红色表示离线。悬停时卡片上浮并增加阴影效果。

#### 设备编辑与远程操作

**编辑**——弹出编辑弹窗，可修改设备名称（必填）、设备类型（必填，五种类型）、所属区域（必填，从区域树加载）、楼层（必填，1F-6F/B1/B2）、IP 地址（必填）和分辨率（必填）。保存时进行表单验证。

**远程重启**——点击"重启"按钮后弹出确认对话框，确认后系统向目标设备发送远程重启指令，操作成功后自动刷新设备列表。

## 3.11.5 系统配置

### 功能入口

信息发布 → 系统配置

### 功能描述

系统配置以标签页形式组织四项系统级配置：设备类型、流程实例、审批流配置和园区隔离。

#### 设备类型

管理信息发布设备的类型定义。数据表格展示类型名称、描述和设备数量。支持新增、编辑和删除操作（删除前弹出确认对话框）。

新增/编辑弹窗配置：类型名称（必填，最长 50 字符）和描述（文本域，最长 200 字符）。

#### 流程实例

管理各园区的流程实例绑定关系。数据表格展示实例名称、关联审批流、适用园区、状态（启用/停用开关）和更新时间。

编辑弹窗配置：实例名称（必填，最长 50 字符）、关联审批流（必填，下拉选择已配置的审批流）、适用园区（必填，全部园区/A栋/B栋/C栋）和状态开关。状态切换直接调用保存 API 即时生效。

#### 审批流配置

管理投放审批的审批流程定义。数据表格展示流程名称、审批节点（以箭头分隔的标签链可视化展示，如"部门主管 → 园区管理员 → 总部审批"）、节点数、更新时间和状态开关。

新增/编辑弹窗（宽度 600px）配置：流程名称（必填，最长 50 字符）和审批节点动态列表。

**节点配置**——可用的审批角色包括：部门主管、园区管理员、总部审批、安全总监。每个节点为一个下拉选择框，支持添加和删除节点。至少需要一个审批节点，每个节点不可为空。系统预置三种典型审批流：
- 一级审批：园区管理员（适用于低风险投放）
- 二级审批：部门主管 → 园区管理员（适用于中风险投放）
- 三级审批：部门主管 → 园区管理员 → 总部审批（适用于高风险投放）

#### 园区隔离

管理多园区间的数据安全隔离策略。数据表格展示园区名称、是否隔离（是/否开关）、允许互通园区（彩色标签列表）和更新时间。

编辑弹窗配置：园区名称（编辑时只读）和隔离开关（隔离/互通）。启用隔离后可勾选允许互通的园区（复选框组，从其他园区中选择），未勾选任何互通园区时显示"完全隔离"提示。

园区隔离机制确保各园区的信息发布数据在默认情况下相互独立。当需要跨园区协作时（如集团统一发布通知），可通过配置互通园区实现指定园区间的数据共享和投放联动。状态切换直接调用保存 API 即时生效。

## 3.11.6 超出标书范围的能力

本系统在标书要求的四大功能之外，额外提供以下增强能力：

**四种排期模式全覆盖**——除标书要求的每周、每天、单次、自定义时间四种排期模式外，系统将每种模式以独立的可视化表单区域呈现。每天模式设置每日固定时段，每周模式支持按星期组合勾选，单次模式精确到特定日期，自定义模式支持不连续的多日期选择，满足从日常循环播放到临时活动通知的全场景排期需求。

**四种内容类型动态配置**——投放内容类型选择后，内容配置区域动态切换对应的配置表单。视频投放提供文件上传器，多屏投放提供屏幕数量选择器（2-16 屏），网页投放提供 URL 输入框，直播投放提供直播流地址输入框。每种类型的配置项精确匹配其业务特征，避免无关字段的干扰。

**风险等级自动评估**——系统根据投放的目标设备数量自动评估风险等级（低/中/高），以彩色标签实时展示。全部设备投放标记为高风险，5 台以上为中风险，5 台及以内为低风险。风险等级不仅在投放配置界面实时显示，也在审批管理列表中展示，帮助审批人快速识别需要重点关注的投放申请。

**可视化审批流配置**——审批节点以标签链形式在表格中可视化展示（如"部门主管 → 园区管理员 → 总部审批"），一目了然地呈现审批层级。系统预置三个等级的审批流模板，支持自由组合四种审批角色，新增/删除节点实时更新。

**双视图设备管理**——设备列表支持表格视图和卡片视图一键切换。表格视图适合批量数据查看和排序，卡片视图以彩色左边框标识在线状态，悬停时卡片上浮，提供更直观的设备状态感知体验。

**园区数据安全隔离**——通过园区隔离配置实现多园区间的信息发布数据隔离，支持配置互通园区白名单。默认完全隔离确保各园区的投放内容、设备数据和审批流程互不干扰，同时支持按需开放指定园区间的数据互通，兼顾安全性与灵活性。

**独立后端微服务**——信息发布系统拥有独立的 NestJS 微服务架构，支持 Docker 独立部署或嵌入主进程两种运行模式，提供完整的 Swagger API 文档（`/publish/docs`），通过 MQTT 协议实现微服务间通信和健康检查，JWT 认证与主系统一致。
