## 软件详细信息

### 硬件环境
- **软件开发硬件环境**：
  PC机：Intel Core i7或同等规格处理器，RAM≥16GB，硬盘≥512GB。
- **软件运行硬件环境**：
  工业边缘网关：x86 四核≥1.8GHz，RAM≥8GB，SSD≥128GB，双千兆网口，RS-485×2/RS-232×2，CAN（可选），DI/DO I/O，4G/5G 模块（可选）。
  现场设备与传感器：照明/空调（多联机/风机盘管）/新风/窗帘/门禁/电梯控制器，温湿度/门磁/人体/水浸等传感器。
  能耗计量：电/水/气/热表（RS-485/MBus），集中采集器。
  服务器（管理与云同步）：x86 8核，RAM≥16GB，SSD≥512GB；或云主机同等规格。
  网络与供电：千兆/万兆交换机、UPS≥1KVA、PoE（如需）。

### 软件环境
- **开发该软件的操作系统**：Linux（Ubuntu 22.04）/ Windows 11 / macOS 14
- **软件开发环境/开发工具**：Node.js 20.x、Vite、Vue 3、TypeScript 5.x、NestJS 10.x、pnpm/npm
- **该软件的运行平台/操作系统**：Linux（Ubuntu 22.04）
- **软件运行支撑环境/支持软件**：Nginx、PostgreSQL 15、Redis 7、MQTT Broker（EMQX/Mosquitto）、Docker、TDengine、ZLMediaKit、Node-RED

### 编程语言
- **编程语言**：TypeScript 5.x、SQL
- **源程序量**：约12000行

### 开发目的
- **内容**：为楼宇设备提供多协议接入、边缘处理与云端协同能力。

### 面向领域/行业
- **内容**：智慧楼宇、园区物联网边缘接入与设备管理行业。

### 软件主要功能
- **内容**：
  本软件实现楼宇物联网边缘平台的设备接入与云端协同管理，包括多种物联网协议接入（Modbus/BACnet/OPC UA/MQTT等）、设备模型与点位管理、设备分组与状态实时监控、MQTT消息桥接与主题路由、边缘时序数据存储（TDengine）、流媒体服务接入（ZLMediaKit）、边缘管理系统（NestJS后端+Web前端）与总部平台数据同步、云边协同心跳与断线续传、数据库服务监控、消息流量监控与系统配置管理。

### 软件主要技术特点
- **分类**：物联网软件 嵌入式软件 智慧城市软件
- **详细说明**：
  采用NestJS模块化微服务架构（Auth/Monitor/Mqtt/Streaming/Devices/Platform/Database）；基于MQTT协议实现边缘内部组件解耦通信与云端Broker桥接转发，主题规范为/{spaceCode}/{serviceType}/{action}；Node-RED流式编排实现协议转换与边缘逻辑处理；TDengine时序数据库存储设备遥测数据；平台注册、心跳上报、桥接自愈与影子表同步机制实现云边协同；JWT认证与RBAC权限控制保障安全。
