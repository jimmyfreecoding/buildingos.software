### 软件主要功能
- **内容**：
  本软件实现园区安防管理全流程闭环，包括十五大功能模块：（一）安防指挥中心——以AirocovMap三维室内地图为核心交互载体，集成设备点位标注、实时告警定位、楼层切换和图例标识，右侧面板以选项卡布局提供点位列表（支持设备类型筛选、关键字搜索、地图飞行定位和Jessibuca视频预览弹窗）和实时告警列表（时间倒序展示，点击飞行定位，支持空状态提示）；（二）视频监控——包含监控设备管理和视频调阅两个选项卡，设备管理支持摄像头CRUD、按名称和状态组合筛选、PTZ协议配置，拉流操作触发addStreamProxy将RTSP流注册到ZLMediaKit，删除设备时同步调用delStreamProxy释放流媒体资源；（三）视频巡更——左右分栏三面板布局（路线+计划+任务），巡更路线管理支持按顺序编排多个摄像头形成虚拟巡更路径，巡更计划配置执行时间段和间隔分钟数，巡更任务支持手动创建、状态筛选和异常上报；（四）消防监测——三个选项卡涵盖设备状态监控（6类消防设备类型、4状态统计卡片、告警时间记录）、告警定位（按级别和处理状态筛选、支持ackFireAlarm确认操作）和安消联动规则配置（触发条件+联动动作+目标设备）；（五）告警类型管理——按四个类别（紧急事件/消防事件/漏水事件/烟感事件）分选项卡展示告警记录，每个类别独立查询分页，底部附告警类型说明卡片；（六）告警排班——人员信息、特定日期排表、周排表三种排班方式叠加，按特定日期>周排表>人员默认规则优先级裁决，确保7×24小时安防监控人力覆盖；（七）告警声音策略——全局声音开关/音量/播报类型配置，按告警级别（低/中/高/紧急）分别绑定声音文件、重复次数和间隔时间，支持TTS语音播报/蜂鸣/自定义音频三种模式；（八）告警白名单——按对象类型（人员/车辆/设备/陌生人）和白名单类型（误报加白/临时通行/设备维护）管理告警豁免，配置有效期自动过期，支持关键字和类型组合筛选；（九）告警升级规则——按告警级别配置处置时限和超时动作（升级级别/通知上级/自动分发），支持声音/弹窗/短信/飞书多渠道通知，系统自动计时超时触发升级；（十）告警聚合——汇聚视频监控/周界防范/门禁系统/消防报警多源告警统一展示，来源筛选按钮组切换，行展开查看合并详情；（十一）告警工单——告警事件转可跟踪工单，支持创建/分配/处理/删除全流程，一键查询事发位置周边20米摄像头列表辅助远程确认；（十二）安防分区——按空间和设备维度划分安防责任区，配置分发岗位和分发人员，支持临时白名单管理，告警定向推送到分区责任人；（十三）事件规则引擎——合并策略（配置合并窗口/合并字段/最大合并数实现告警风暴抑制）+过滤规则（条件构建器定义字段/运算符/值，AND逻辑组合）+分发规则（触发条件+分发目标+多渠道通知）+SOP模板（分步骤标准处置程序，每步骤配置责任人角色和时限），四环节串联成完整告警处理管线；（十四）流媒体平台——平台状态监控（4服务卡片+ZLMediaKit/SIP信息展示）、转码模板管理、推流设备管理、活跃推流列表、GB28181国标设备管理和服务器资源实时监控（CPU/内存/带宽/磁盘）六大选项卡；（十五）流媒体直播视频墙——支持1/4/9/16画面分割，每个画面独立运行Jessibuca播放器，摄像头选择面板+视频网格布局，支持PTZ云台控制和画面截图。（运营工具）告警中心——空间树+告警列表双栏布局，支持告警接收/误报标记/处理完成全生命周期操作和Excel导出；（运营工具）消防应急——消防告警处置+应急程序配置+黑名单管理（人脸照片上传至外部API）+人脸轨迹搜索（以图搜图跨系统检索）。系统通过MQTT协议订阅security/#主题，独立运行端口3015；采用NestJS微服务架构集成MQTT消息通信，TypeORM支持MySQL/PostgreSQL/SQLite三数据库无缝切换。

### 软件主要技术特点
- **分类**：智慧城市软件 安防管理软件 物联网软件
- **详细说明**：
  整体采用Vue3+TypeScript+NestJS全栈微服务架构，独立运行端口3015。后端基于NestJS 10.x框架，采用模块化分层设计（Controller→Service→Repository→Entity），共8个控制器、7个服务、13个实体类和6组DTO，通过@nestjs/swagger自动生成API文档（/security/docs端点）。MQTT微服务通信采用@nestjs/microservices的Transport.MQTT传输层，订阅security/#通配符主题实现跨子系统消息路由。TypeORM多数据库适配层通过环境变量（DB_TYPE）自动切换MySQL/PostgreSQL/SQLite三种数据库，所有13个实体类通过synchronize:true自动建表，实体涵盖巡更（路线/计划/任务三实体）、消防（设备/告警/联动规则三实体）、工单、告警事件、排班（人员/特定日期/周排三实体）、流媒体（设备/转码模板二实体）全业务域。RESTful API共7组45+接口，统一返回{code,msg,data}格式，通过extractUser工具函数从JWT请求头提取操作人信息。前端采用Vue 3 Composition API+defineOptions显式组件命名，Element Plus组件库提供el-card/el-table/el-tag/el-form/el-switch/el-progress等UI组件，ECharts 5通过vue-echarts的v-chart组件封装实现可视化图表。视频监控模块集成Jessibuca播放器（支持H.264/H.265实时解码），通过JSAPI接口实现播放器实例管理、PTZ云台控制和画面截图。流媒体平台对接ZLMediaKit服务器的REST API，实现addStreamProxy/delStreamProxy流代理管理、GB28181国标设备注册与推流控制。事件规则引擎采用管道过滤器模式，告警事件依次经过合并策略（窗口时间+多维字段AND逻辑聚合）、过滤规则（条件构建器：字段选型+运算符+值，多条件AND）、分发规则（触发条件匹配→分发目标+多渠道通知）、SOP模板（分步骤标准处置流程）四个管道环节。合并引擎按配置的时间窗口和合并字段维度（设备/位置/告警类型/区域多选AND），将符合条件的多条告警聚合为1条，原始告警JSON附加在聚合体展开详情中。告警升级引擎基于计时器机制，按告警级别配置处置时限，超时自动执行升级动作（级别提升/上级通知/群组分发）并通过声音/弹窗/短信/飞书多渠道推送。巡更系统采用路线（摄像头有序编排）→计划（时间段+间隔）→任务（手动创建+状态跟踪+异常上报）三层领域模型，实现视频巡更全生命周期管理。前端权限守卫统一使用Admin角色校验，所有页面组件通过Vab框架组件（vab-card/vab-query-form/vab-pagination/vab-icon）和remixicon图标库实现统一的UI设计语言。
