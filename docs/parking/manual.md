## 1. 引言

### 1.1 编写目的
本操作说明书旨在详细阐述《智能楼宇智能停车管理系统 buildingos.parking》的功能架构、操作流程及维护方法。文档面向系统的最终用户（包括园区管理人员、安保人员、前台接待人员）以及系统管理员，提供标准化的操作指引，帮助用户快速掌握从停车资源配置、车辆登记管理、车位申请审批、道闸出入管控到运营统计分析的全流程操作，确保园区停车管理的规范化与智能化。

### 1.2 定义
*   **系统/本系统**：指《智能楼宇智能停车管理系统 buildingos.parking》。
*   **停车区域**：指对物理停车场的逻辑抽象（如"B1层停车区""B2层停车区"），是资源层级模型中的第一级，包含若干停车位。
*   **白名单**：指允许免费通行或不受限通行的车辆登记列表，通常包含公司自有车辆、高管专车、政府接待车辆等。
*   **黑名单**：指被限制进入园区的风险车辆登记列表，包含禁止入场、限制时段、欠费未缴三种限制类型。
*   **访客联动**：指停车系统与访客管理系统的自动对接机制，访客预约通过后车牌自动同步至停车系统并授权通行。

## 2. 系统概述

### 2.1 系统用途
《智能楼宇智能停车管理系统 buildingos.parking》是专为现代化智慧楼宇和园区打造的数字化停车管理平台。系统取代了传统的人工登记和纸质票据管理模式，通过"停车区域→停车位"两级资源层级模型实现停车资源的精细化配置。系统与道闸、车牌识别摄像头、充电桩等IoT设备深度集成，实现车辆入场自动识别与离场自动放行；与访客系统原生联通，实现访客车辆凭预约自动通行。在提升园区通行效率的同时，通过黑白名单管控和违规检测引擎，构建园区车辆安全管控体系。

### 2.2 软件功能概述
本系统主要包含以下核心功能模块：
1.  **资源管理**：按"停车区域→停车位"两级层级组织停车资源，支持区域平面图拖拽上传和车位批量生成，提供车位类型与用途的精细化配置。
2.  **车辆管理**：覆盖员工与访客车辆的登记注册，支持白名单免费通行、黑名单限制入场（禁止入场/限制时段/欠费未缴）和VIP车辆入场自动提醒。
3.  **车位申请与分配**：员工在线提交停车位申请，管理员可人工审核或启用自动分配规则引擎，支持按区域优先级与配额自动匹配最优车位。
4.  **进出管理**：车辆出入全量流水记录（含入场抓拍照片），支持错停、超时停放、堵塞通道、超速四类违规的检测与审核处理，以及访客系统联动配置。
5.  **运营统计**：实时大屏展示在园车辆数和出入趋势，车位使用率环形图分析各类型车位占用，停车统计支持按天/周/月粒度多维度对比分析。
6.  **充电桩监控**：以卡片网格实时展示充电桩的空闲/使用中/故障状态、当前功率和充电车辆信息。

### 2.3 软件运行环境
*   **硬件环境**：
    *   **服务端**：推荐配置 8核 CPU，16GB 内存，512GB SSD 存储。
    *   **客户端**：支持 Windows/macOS 操作系统的 PC 机，建议屏幕分辨率 1920x1080 以上。
    *   **外设支持**：兼容主流车牌识别摄像头、道闸控制器、地感线圈、LED显示屏及交流/直流充电桩。
*   **软件环境**：
    *   **浏览器**：建议使用 Google Chrome 80+、Microsoft Edge 或 Firefox 等现代浏览器。
    *   **服务端系统**：Linux (Ubuntu 20.04+/CentOS 7+) 或 Windows Server 2019。

系统采用B/S架构，用户通过浏览器访问指定网址即可进入登录界面。界面设计简洁大气，突显智慧停车科技感。
*   **操作步骤**：
    1. 打开浏览器，输入系统URL地址。
    2. 进入登录页面后，输入已授权的用户名和密码。
    3. 点击"登录"按钮，系统验证账号有效性。
    4. 验证通过后，页面自动跳转至系统首页。

### 3.2 资源管理

#### 3.2.1 停车区域管理
停车区域管理是系统资源层级的第一级，实现对地下停车场各楼层区域的统一配置与维护。页面以查询表单加数据表格的经典布局呈现，顶部查询栏支持按楼层（B1/B2/B3）和状态（启用/停用）筛选区域，右侧"新增区域"按钮用于创建新的停车区域。
*   **功能说明**：
    - **新增区域**：弹出600px宽度的表单弹窗，包含区域名称（文本输入）、所属楼层（下拉选择B1/B2/B3）、总车位数（数字输入，最小1最大9999）三个必填字段。保存后系统自动按总车位数批量生成对应的停车位记录。
    - **上传平面图**：区域保存后，在编辑弹窗中可拖拽或点击上传区域平面图（支持JPG/PNG/GIF格式），已上传的平面图以缩略图预览展示，鼠标悬浮显示"点击重新上传"图标，点击可放大查看。
    - **编辑与删除**：每行提供编辑和删除操作。删除区域时弹出警告对话框，提示"将同时删除该区域下的所有停车位"，确认后级联删除。
*   **操作步骤**：
    1. 点击左侧"资源管理→停车区域管理"进入页面。
    2. 点击"新增区域"按钮，填写区域名称、选择楼层、输入总车位数后保存。
    3. 保存成功后再次编辑该区域，上传楼层平面图。
    4. 通过楼层和状态筛选框快速定位目标区域。

![停车区域管理](image-2.png)
*图 3-2-1 停车区域管理界面*

#### 3.2.2 停车位管理
停车位管理是资源层级的第二级，提供对每个车位的精细化配置。页面支持按区域、类型、用途、状态四个维度的组合筛选，数据表格每行展示车位编号、所属区域、类型、用途、当前状态和当前占用车牌号。表格支持勾选多行进行批量操作。
*   **功能说明**：
    - **车位类型**：平面车位（标准轿车）、新能源车位（带充电桩，绿色标签）、大型车位（SUV/商务车，橙色标签）、紧凑车位（小型车辆，蓝色标签）。
    - **车位用途**：普通车位（员工日常停放）、访客车位（与访客系统联动，红色标签）、VIP车位（高管及重要来宾）。
    - **车位状态流转**：空闲→（车辆入场）→已占用→（车辆离场）→空闲；空闲→（申请审批通过）→已预约→（车辆入场）→已占用；任意状态→（管理员批量操作）→维护中。
    - **批量操作**：勾选多行后顶部出现批量操作工具栏，可对选中车位批量设置为"维护中"或"空闲"状态。
*   **操作步骤**：
    1. 进入"资源管理→停车位管理"页面。
    2. 通过区域、类型、用途、状态四维筛选框定位目标车位。
    3. 点击某车位的"编辑"按钮，在500px弹窗中修改车位类型、用途和状态。
    4. 勾选多个车位后点击批量操作按钮统一修改状态。

### 3.3 车辆管理

#### 3.3.1 车辆登记
车辆登记模块管理所有进出园区的车辆信息，区分员工车辆和访客车辆。顶部查询栏支持按车牌号、人员类型（员工/访客）、状态（启用/停用）三维筛选。数据表格展示车牌号、车主姓名、联系电话、所属部门、车辆型号、人员类型和启用状态。
*   **功能说明**：
    - **新增车辆**：弹出600px宽度的表单弹窗，车牌号使用专用车牌输入组件（自动大写、限制8位），其他字段包括车主姓名、联系电话、所属部门、人员类型（员工/访客）、车辆型号、车辆颜色。
    - **查看与删除**：管理员可查看已登记车辆的完整信息，在车辆报废、员工离职或登记错误等场景下可删除已登记车牌记录。
*   **操作步骤**：
    1. 进入"车辆管理→车辆登记"页面。
    2. 点击"新增车辆"按钮，使用车牌输入组件录入车牌号并填写相关信息后保存。
    3. 通过查询栏按车牌号或人员类型筛选车辆。
    4. 对离职员工或报废车辆，点击"删除"按钮移除登记记录。

![车辆登记](image-4.png)
*图 3-3-1 车辆登记界面*

#### 3.3.2 白名单管理
白名单管理用于维护免费通行或不受限通行的车辆列表，典型场景包括公司自有车辆、高管专车、政府接待车辆、长期合作供应商车辆等。查询栏支持按车牌号和状态（启用/已过期）筛选。
*   **功能说明**：
    - **新增白名单**：录入车牌号、车主姓名、通行原因（多行文本）、有效期起始日期和截止日期。有效期到期后自动标记为"已过期"，道闸放行行为恢复为普通车辆逻辑。
    - **过期标红**：数据表格中超过有效期的条目以红色字体标注。
*   **操作步骤**：
    1. 进入"车辆管理→白名单"页面。
    2. 点击"新增"按钮，填写车牌号、车主姓名、通行原因和有效期后保存。
    3. 有效期到期后系统自动标记已过期，管理员可编辑续期。

![白名单管理](image-5.png)
*图 3-3-2 白名单管理界面*

#### 3.3.3 黑名单管理
黑名单管理用于限制风险车辆进入园区，典型场景包括有违停记录的车辆、欠费车辆、安全风险车辆等。查询栏支持按车牌号搜索，数据表格以彩色标签区分限制类型。
*   **功能说明**：
    - **禁止入场**（红色标签）：车辆通过道闸时直接拒绝抬杆，禁止进入园区，适用于严重违规或有安全风险的车辆。
    - **限制时段**（橙色标签）：车辆在指定时段内（如工作日09:00-18:00以外）禁止进入园区。
    - **欠费未缴**（蓝色标签）：车辆可正常进出，但在出口处提示欠费信息，需补缴后方可再次入场。
    - **自动解除**：黑名单有效期到期后自动解除限制。
*   **操作步骤**：
    1. 进入"车辆管理→黑名单"页面。
    2. 点击"新增"按钮，填写车牌号、车主姓名、选择限制类型和有效期后保存。
    3. 违规审核确认后可一键将违规车辆加入黑名单。

![黑名单管理](image-6.png)
*图 3-3-3 黑名单管理界面*

#### 3.3.4 VIP管理
VIP管理用于维护重要来宾和高级管理人员的车辆信息及提醒联系人。查询栏支持按VIP姓名和车牌号搜索。数据表格展示VIP姓名、车牌号、联系电话、提醒联系人姓名、提醒联系人电话和启用状态。
*   **功能说明**：
    - **入场提醒**：当VIP车辆入场时，系统自动向提醒联系人发送通知（如"张总的车辆已到达园区北门入口"），方便接待人员提前准备。
    - **启用控制**：VIP状态通过开关控制启用/停用，停用的VIP不再触发入场提醒。
*   **操作步骤**：
    1. 进入"车辆管理→VIP管理"页面。
    2. 点击"新增VIP"按钮，填写VIP姓名、车牌号、联系电话及提醒联系人信息。
    3. 通过启用/停用开关控制VIP入场提醒的激活状态。

### 3.4 车位申请与分配

#### 3.4.1 申请提交
员工通过此模块发起停车位使用申请。页面顶部为五个状态标签页（全部、待处理、已通过、已拒绝、已分配），方便员工追踪申请进展。数据表格展示申请编号、申请人、车牌号、车辆型号、申请类型（长期/临时，彩色标签区分）、申请时间和当前状态。
*   **功能说明**：
    - **新增申请**：弹出600px宽度的表单弹窗，包含车牌号（专用输入组件）、车辆型号、车辆颜色、意向区域（下拉选择已启用的停车区域）、申请类型（长期/临时）、联系电话。
    - **查看详情**：点击"查看详情"弹出详情弹窗，以两列描述列表展示申请的完整信息。若已分配额外展示分配的车位信息，若已拒绝额外展示拒绝原因。
    - **取消申请**：待处理状态的申请提供"取消"按钮，申请人可主动撤销。
*   **操作步骤**：
    1. 进入"车位申请→申请记录"页面。
    2. 点击"新增申请"按钮，填写车牌号、车辆信息、意向区域和申请类型后提交。
    3. 在各状态标签页中查看申请的处理进展。

![车位申请提交](image-8.png)
*图 3-4-1 车位申请提交界面*

#### 3.4.2 审核与分配
管理员在此模块统一处理员工的停车位申请。与申请端相同的五个状态标签页，待处理状态的申请提供"审核"和"自动分配"两个操作按钮。
*   **功能说明**：
    - **人工审核**：弹出700px宽度的审核弹窗，上半部分展示申请详情（只读），下半部分为审核操作区（分配区域下拉框、分配车位下拉框按区域联动过滤、拒绝原因文本框）。底部提供取消、拒绝（需填写原因）、通过并分配（需选择区域和车位）三个操作按钮。
    - **自动分配**：系统根据预设的自动分配规则引擎自动匹配最优车位，弹出确认对话框后一键完成分配。
    - **自动分配规则配置**：弹窗内为可编辑表格，每行对应一个停车区域，包含区域名称、分配配额（滑块0-100）、优先级（数字1-99，数值越小优先级越高）、启用开关。系统按优先级从高到低、配额未满的顺序扫描各区域，找到第一个可用空闲车位后停止。
*   **操作步骤**：
    1. 进入"车位申请→审核与分配"页面。
    2. 在"待处理"标签页中，点击某申请的"审核"按钮进行人工审核分配。
    3. 或点击"自动分配"按钮，系统自动匹配车位。
    4. 点击右上角"自动分配规则"按钮，配置各区域的分配配额和优先级。

### 3.5 进出管理

#### 3.5.1 进出记录
进出记录模块提供车辆进出园区的全量流水查询。顶部查询栏支持按车牌号模糊搜索、入场时间范围、出场时间范围三维筛选。数据表格展示车牌号、车辆名称、车辆类型（员工/访客/VIP，彩色标签区分）、入场抓拍照片（40×40缩略图，点击可放大预览）、访客信息（访客类型时显示）、入场时间、出场时间、停车时长和通行车道。
*   **功能说明**：
    - 该模块为纯查询视图，不提供编辑或删除操作，确保通行记录不可篡改。
    - 入场抓拍照片通过图片预览组件展示，点击可全屏放大查看。
*   **操作步骤**：
    1. 进入"进出管理→进出记录"页面。
    2. 设置车牌号关键词、入场/出场时间范围后点击查询。
    3. 点击入场抓拍照片缩略图可放大查看车辆照片。

![进出记录](image-10.png)
*图 3-5-1 进出记录界面*

#### 3.5.2 违规管控
违规管控模块覆盖从违规检测、审核确认到撤销的全流程管理。页面顶部为四个状态标签页（全部、待审核、已确认、已撤销），数据表格展示违规车牌号、违规类型（错停/超时停放/堵塞通道/超速，彩色标签）、违规描述、检测时间、现场照片（50×50缩略图，点击放大）和处理状态。
*   **功能说明**：
    - **违规类型**：错停（橙色，非指定车位或占用人行道）、超时停放（红色，"僵尸车"检测）、堵塞通道（红色，阻碍通行）、超速（蓝色，园区内超速）。
    - **审核处理**：点击"审核"按钮弹出600px审核弹窗，顶部放大展示违规现场照片（200×150），下方展示违规详情，底部提供审核备注文本框和确认为违规/撤销两个操作按钮。
    - **违规规则配置**：可设置最长停放天数（每日自动检测僵尸车）、违规告警通知开关和自动检测时段。
*   **操作步骤**：
    1. 进入"进出管理→违规管控"页面。
    2. 在"待审核"标签页中，点击某违规记录的"审核"按钮。
    3. 查看现场照片和违规详情后，选择确认违规或撤销。
    4. 点击"违规规则"按钮配置自动检测参数。

![违规管控](image-11.png)
*图 3-5-2 违规管控界面*

#### 3.5.3 访客联动配置
访客联动配置模块实现停车系统与访客管理系统的自动对接。页面为单一配置表单（最大宽度600px），包含启用联动总开关、自动白名单访客开关、最大停留时长设置（1-720小时）和同步间隔设置（1-1440分钟）。
*   **功能说明**：
    - **启用联动**：总开关，开启后访客预约时填写的车牌号自动同步至停车系统。
    - **自动白名单访客**：审批通过的访客车牌自动加入白名单，在到访时间段内享受免费通行，离场后自动失效。
    - **超时告警**：访客车辆超过最大停留时长仍未离场时，系统自动产生超时告警。
*   **操作步骤**：
    1. 进入"进出管理→访客联动"页面。
    2. 开启/关闭联动总开关和自动白名单访客开关。
    3. 设置最大停留时长和同步间隔参数后保存，配置即时生效。

![访客联动配置](image-12.png)

### 3.6 运营统计

#### 3.6.1 实时大屏
实时大屏以可视化仪表盘形式展示停车业务的实时运行状态，适用于监控中心大屏投放，数据每30秒自动刷新。顶部三张统计卡片分别展示当前在园车辆数（蓝色主题）、今日入场总数（绿色主题）和今日出场总数（橙色主题），每张卡片采用带彩色左边框设计，数值粗体大字展示。
*   **功能说明**：
    - **24小时出入趋势图**：平滑双折线分别展示今日24小时各时段的入场和出场车辆数量，折线下方填充半透明渐变区域，X轴为小时刻度（0-23时）。
    - **车位使用率环形图**：环形图（内径40%，外径70%）展示当前车位占用分布，各分类以不同颜色区分并标注百分比。
    - **近期出入记录**：以卡片包裹的表格展示最近通行的车辆记录，包含车牌号、车辆类型（彩色标签）、入场时间和通行车道。
*   **操作步骤**：
    1. 进入"运营统计→实时看板"页面。
    2. 查看顶部统计卡片了解实时数据概览。
    3. 观察趋势图和环形图分析车流规律和车位占用情况。

![实时大屏](image-13.png)
*图 3-6-1 实时大屏界面*

#### 3.6.2 车位使用率
车位使用率模块从车位类型维度分析停车资源的利用效率，数据每1小时自动刷新。左栏环形图展示已占用车位与可用车位的总体比例，中心显示使用率百分比。右栏进度条列表展示各类型车位的占用详情（员工车位、访客车位、VIP车位、新能源车位），每项显示彩色类型标签、进度条和已用/总数数值。
*   **操作步骤**：
    1. 进入"运营统计→车位使用"页面。
    2. 查看环形图了解总体车位占用比例。
    3. 通过底部表格按区域查看各区域的汇总使用情况。

![车位使用率](image-14.png)
*图 3-6-2 车位使用率界面*

#### 3.6.3 停车统计
停车统计模块提供历史周期的停车业务数据分析与对比。顶部筛选栏包含日期范围选择器和统计粒度切换（按天/按周/按月）。常驻展示四张实时卡片（今日入场数、今日出场数、平均停留时长、当前在园车辆数）。
*   **功能说明**：
    - **24小时车辆趋势图**：按筛选日期范围展示入场/出场折线图，支持平滑曲线和交叉Tooltip。
    - **访客停车时长按部门分布**：柱状图展示各部门访客的平均停车时长，柱宽40%。
    - **周期汇总卡片**：当筛选特定周期时展示总入场数、总出场数、平均停留时长和峰值日（含当日入场数）。
    - **周期流量明细表**：展示周期内每一天的入场数和出场数明细，支持斑马纹表格。
*   **操作步骤**：
    1. 进入"运营统计→停车统计"页面。
    2. 设置日期范围和统计粒度（按天/按周/按月）后点击查询。
    3. 查看趋势折线图和部门分布柱状图进行数据分析。
    4. 通过周期汇总卡片和流量明细表了解规律性特征。

### 3.7 充电桩状态
充电桩状态模块以6列卡片网格直观展示所有充电桩的实时运行情况。每张卡片展示桩编号（顶部粗体）、状态标签（右上角）、所在位置、当前功率和当前充电车辆（仅"使用中"状态显示）。

    - **功率档位**：空闲0kW、使用中60kW、使用中120kW三种档位。
*   **操作步骤**：
    1. 进入"充电桩状态"页面。
    2. 通过卡片网格快速浏览所有充电桩的实时状态。
    3. 关注红色故障卡片，及时进行设备维护。

### 3.8 车辆通行管理
车辆通行管理模块（Car Pass）提供车位沙盘可视化和VIP车辆通行配置功能。

#### 3.8.1 车位沙盘
车位沙盘以可视化仪表盘形式监控停车场全局状态。顶部四张统计卡片（带渐变色背景和图标）分别展示总车位数（蓝色背景+环比百分比）、已占用车位（白色背景+今日标签）、员工车位今日总时长和访客车位今日总时长。
*   **功能说明**：
    - **车位占用环形图**：多段环形图展示各类型车位的占用分布（员工月租、访客车位、高管车位、员工临停），每段圆角设计、白色边框分隔。
    - **24小时吞吐量折线图**：双线展示24小时车辆流量，平滑曲线、渐变填充区域。
    - **车辆分类横向柱状图**：展示各车辆类型的数量分布，柱宽15px、圆角设计、右侧数值标签。
*   **操作步骤**：
    1. 进入"通行管理→车辆通行→车位沙盘"页面。
    2. 查看顶部统计卡片了解停车场全局概况。
    3. 通过环形图和柱状图分析各类型车位和车辆的分布情况。

![车位沙盘](image-17.png)
*图 3-8-1 车位沙盘界面*

#### 3.8.2 车辆通行记录
车辆通行记录提供车牌级别的通行流水查询。查询栏支持按车牌号搜索，数据表格展示车牌号、车主姓名、所属部门、邀约人、车辆类型（VIP/员工月租/访客临停，深色标签）、入场时间、出场时间和停车时长。
*   **功能说明**：
    - **VIP车辆设置**：弹窗上半部分为VIP车辆添加表单（车牌号输入+放行流程选择），放行流程包含VIP放行流程、政府接待流程、高管放行流程等选项。下半部分为已有VIP车辆列表表格。
*   **操作步骤**：
    1. 进入"通行管理→车辆通行→通行记录"页面。
    2. 按车牌号关键词搜索通行记录。
    3. 点击"VIP车辆设置"按钮，添加VIP车辆并选择放行流程。
